# Jake · UGC Portfolio

Static, single-page recreation of the public Jiro Build preview:
https://jiro.build/templates/portfolio/ugc-creator-portfolio-landing-page-jake

Run locally with any static HTTP server, for example:

    python3 -m http.server 4173

Included interactions:
- Scroll-triggered reveal and count-up animations
- Hero card hover lifts and CTA transitions
- Portfolio category filters
- Brand and result marquees
- Testimonial carousel with autoplay
- Process step hover states
- Contact brief form feedback state
